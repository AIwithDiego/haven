# Contributing

Thanks for taking a look. Haven is a case study now: I built it, used it every day for three weeks, then retired it (the README says why). I don't plan new features, so the most useful contributions are small.

- **Bugs:** open an issue with the template, especially anything in the approval card, permissions, links or IPC. A reproduction helps most.
- **Questions about the build or the post-mortem:** open a feedback issue. Happy to answer.
- **Pull requests:** small and focused. Say what changed and why, and how you tested it.
- **Before opening one:** run `npm run build` and `npm test` (macOS on Apple Silicon, Node 25), and make sure CI is green.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

I answer issues within a few days.
